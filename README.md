# SPH-HA

Home-Assistant-Integration für das Schulportal Hessen (SPH).

## Lovelace-Karten

SPH-HA liefert mehrere Lovelace-Karten für Stundenplan, Tagesansicht, Rasteransicht, KFG-Vertretungsplan, Hausaufgaben, Lerngruppen und Kalender mit.

Die vollständige Kartenübersicht einschließlich Funktionsweise und aller YAML-Konfigurationsparameter befindet sich unter [`docs/lovelace/README.md`](docs/lovelace/README.md).

Weitere Informationen zur Installation und Konfiguration der Integration befinden sich in den übrigen Abschnitten dieses README beziehungsweise in `docs/`.
